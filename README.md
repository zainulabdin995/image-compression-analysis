# Image Compression Analysis: JPEG vs JPEG2000

## Overview
This Digital Signal Processing (DSP) project evaluates lossy image compression techniques by implementing and comparing JPEG (Discrete Cosine Transform) and JPEG2000 (Discrete Wavelet Transform) algorithms. 



## Tech Stack
* **Language:** Python
* **Libraries:** OpenCV, NumPy, PyWavelets, Matplotlib

## Evaluation Metrics
The algorithms are mathematically benchmarked across various compression ratios using:
* Compression Ratio (CR)
* Peak Signal-to-Noise Ratio (PSNR)
* Structural Similarity Index (SSIM)

## How to Run
1. Clone the repository and install dependencies.
2. Run the Jupyter Notebook in `notebooks/compression_analysis.ipynb` to view the step-by-step mathematical transformations, difference images, and metric bar plots.
